# AI Presence Monitor v0.1.1 - Codex Hook Observer

**Data**: 2026-07-16  
**Metodologia**: Protocolo Simplicidade 3

## Objetivos

- Adicionar observer passivo para hooks do Codex.
- Reduzir falsos alertas no Protocolo 2 durante tarefas longas.
- Manter alertas centralizados no monitor.

## Funcionalidades Implementadas

- Comando `codex-hook` para receber JSON por `stdin`.
- Script `hooks/codex_presence_hook.py` para uso direto em `hooks.json`.
- Exemplo de configuracao Codex em `examples/codex/hooks.json`.
- Metodo `PresenceStore.record_observation()` para atividade silenciosa automatica.
- Variaveis `.env` `PRESENCE_CODEX_*` para configurar worker/protocolo/tarefa.
- Testes automatizados do parser e da gravacao.
- Instalador/desinstalador de hooks do Codex com backup, dry-run e idempotencia.

## Qualidade

- Sem dependencia externa nova.
- Sem chamadas de rede dentro do hook.
- 7 testes unitarios passando para a nova logica.

## Arquivos Criados/Modificados

- `ai_presence_monitor/codex_hook.py` - observer passivo do Codex.
- `ai_presence_monitor/store.py` - registro de observacoes.
- `ai_presence_monitor/cli.py` - subcomando `codex-hook`.
- `ai_presence_monitor/config.py` - configuracoes `PRESENCE_CODEX_*`.
- `ai_presence_monitor/interactive.py` - perguntas do observer no menu.
- `hooks/codex_presence_hook.py` - wrapper executavel pelo Codex.
- `examples/codex/hooks.json` - configuracao de exemplo.
- `tests/test_codex_hook.py` - testes unitarios.
- `ai_presence_monitor/codex_hook_installer.py` - instalacao/desinstalacao de `hooks.json`.
- `tests/test_codex_hook_installer.py` - testes do instalador.
