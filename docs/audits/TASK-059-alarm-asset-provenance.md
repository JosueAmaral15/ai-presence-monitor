## Origin

The sound is an original parameterized waveform generated by
`generate_alarm_asset.py`. It contains no recording, sampled sound, downloaded
media or third-party composition. The generator uses only Python standard
library modules.

The mono 16-bit PCM stream runs at 44,100 Hz and contains three repetitions of
an 880 Hz square-wave tone for 180 ms, 80 ms of silence, a 660 Hz square-wave
tone for 180 ms and 200 ms of silence. Its signed amplitude is 10,485, about
32 percent of the 16-bit range. Integer arithmetic makes the PCM stream
independent of platform-specific trigonometric implementations.

## Reproduction

From the repository root:

```bash
python scripts/generate_alarm_asset.py \
  --output assets/ai-presence-alarm.wav
sha256sum assets/ai-presence-alarm.wav
```

`tests/test_alarm_asset.py` generates the file in a temporary directory and
requires both the recorded digest and byte-for-byte equality with the tracked
asset. The canonical Linux bundle includes this document, the generator and
the WAV so recipients can repeat the check without trusting an external media
source.

## Operational Boundary

The asset is optional. Installation, upgrade, service startup and monitor
startup do not play it or modify user configuration. An operator must set an
absolute `RED_ALERT_COMMAND` explicitly. Runtime duration limits,
deduplication and `ai-presence stop-alarm` remain unchanged.
