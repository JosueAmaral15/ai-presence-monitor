# Task 062 - Low-Prerequisite Backlog and Agensi Skill Pack

## Goal

Complete useful work that does not depend on a fresh trusted Codex session,
real quota exhaustion, a second computer, marketplace credentials or external
publication approval.

## Scope

1. Correct the Codex database health note with current read-only evidence,
   without modifying the database or weakening the pending hook gate.
2. Convert the local Agensi candidate into a focused text-only skill pack for
   worker lifecycle, correlated human interaction and guarded continuation.
3. Preserve the installed runtime as a prerequisite instead of embedding an
   installer, secrets, local paths or network access in the pack.
4. Validate every `SKILL.md`, scan the package for unsafe content and record
   the result in `docs/TASKS.md`.

## Acceptance Criteria

- Historical corruption evidence remains recorded, but is not presented as
  the current database state after a successful read-only integrity check.
- The pack contains between two and fifty skills, each with a distinct job,
  name and description.
- Shared safety instructions preserve exact project/session scoping,
  authorization boundaries and evidence-state semantics.
- The package contains text only and no `.env`, token, webhook, personal path,
  executable or environment-harvesting logic.
- Local validators and `git diff --check` pass.
- No Agensi account, payout configuration, upload or publication is attempted.

## External Boundaries

- Task 061 still requires a newly loaded and trusted Codex hook lifecycle.
- Task 058 still requires a naturally exhausted quota that later recovers.
- Task 056 still requires an approved cryptographic pairing design and two
  real computers before active Codex history can be synchronized.
- Tasks 055 and 057 require explicit authorization at each publication
  boundary.
