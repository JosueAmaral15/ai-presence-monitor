## Use cases

- Register the start and finish of AI work against the correct local project.
- Use lifecycle hooks or evidence-backed fallback activity without generating
  timer-only presence.
- Ask a blocking question through the configured Discord fallback and route an
  allowed direct reply to the exact originating session.
- Publish explicit agent results to the local and Discord transcript.
- Continue a documented next task after checking authorization, blockers and
  exact-session identity.
- Distinguish transport initiation from later confirmed session activity.

## Required access and limitations

The buyer needs a separately installed and configured AI Presence Monitor
runtime and an agent capable of running local commands. The pack does not
install the product, provide Discord credentials, enable automation or grant
permission to send input. Compatibility must be claimed only for agent/runtime
combinations that have been tested.
