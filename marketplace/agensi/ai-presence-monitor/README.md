# AI Presence Monitor Operations Pack

This text-only skill pack teaches an AI agent to operate an existing AI
Presence Monitor installation. It does not install the product, configure
accounts, grant authorization or bundle the runtime.

Included skills:

- **AI Presence Worker Lifecycle**: start, observe and finish project-scoped
  work without manufacturing activity.
- **AI Presence Correlated Human Loop**: ask questions and publish explicit
  agent messages with project, session and Discord correlation boundaries.
- **AI Presence Guarded Continuation**: evaluate and perform authorized native
  continuation without confusing transport with confirmed processing.

Prerequisites:

- a locally installed `ai-presence` command;
- project instructions that permit the requested operation;
- any required human authorization and exact session identifier.

The pack intentionally contains no executable, installer, secret, account
identifier, environment reader, network client or machine-specific path.
